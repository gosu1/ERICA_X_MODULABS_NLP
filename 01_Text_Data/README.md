## PRT (Peer Review Template)

- [ ] **1. 주어진 문제를 해결하는 완성된 코드가 제출되었나요?**
  - [단어사전 프로젝트 노트북](./SentencePiece_project_executed.ipynb)에 뉴스 데이터 전처리, SentencePiece 학습, 토큰화 함수와 감정 분류 실험 결과가 있습니다.
  - BPE 8,000과 BiGRU를 사용한 확장 실험에서 검증 정확도는 81.68%, 정제한 테스트 48,361건의 정확도는 81.66%였습니다.
  - 테스트 1,000건은 앞선 보조 실험에서도 확인했으므로 전체 테스트를 완전히 새로운 독립 평가로 볼 수는 없습니다.

- [ ] **2. 핵심 코드의 주석이나 docstring을 보고 이해할 수 있나요?**
  - `sp_tokenize()`는 SentencePiece의 토큰 ID를 텐서로 바꾸고 패딩한 뒤, 단어와 ID의 양방향 사전을 반환합니다. 모델에 입력할 데이터를 만드는 핵심 함수입니다.
  - PAD와 UNK를 분리한다는 주석이 있지만 함수 자체의 매개변수와 반환값을 설명하는 docstring은 없어 보완할 수 있습니다.

- [x] **3. 오류를 해결한 기록이나 추가 실험이 있나요?**
  - MeCab 설치 후 발생한 `Tagger NameError`는 먼저 로드된 `konlpy.tag._mecab` 모듈을 다시 불러와 해결했습니다. 설치 경로와 실행 결과를 노트북에 기록했습니다.
  - 같은 GRU 조건에서 unigram, BPE 2,000, BPE 4,000, Okt를 비교했고, 별도로 학습 데이터와 모델을 확장한 BPE 8,000 실험을 진행했습니다.
  - 확장 실험은 데이터 양과 모델 구조도 달라, 기존 비교 결과와 토크나이저만의 차이로 해석할 수 없습니다.

- [ ] **4. 회고와 실행 흐름이 정리되어 있나요?**
  - 노트북에 실험 결과와 학습 표본, 테스트 재사용 등의 한계가 정리되어 있습니다.
  - 실행 흐름도와 별도의 회고는 없어 추가할 수 있습니다.

- [ ] **5. 코드가 간결하고 효율적인가요?**
  - 토큰화와 평가를 함수로 분리해 재사용한 부분이 있습니다.
  - 긴 코드 셀과 중복 import가 있고 PEP 8 전체 준수 여부는 검증하지 않았습니다. 설정, 학습, 평가 코드를 나누고 중복을 줄이면 읽기 쉬워질 것 같습니다.
